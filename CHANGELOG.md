# Changelog

## 0.1.0 — 2026-11-25

First release, extracted from the Fly UI design system.

- 21 components: AppShell, Sidebar, Toolbar, Tabs, Button, Menu, TextField, Select, Checkbox, SegmentedControl, Switch, Card, Table, Pagination, Badge, EmptyState, Spinner, Skeleton, Toaster / `toast()`, Drawer, Dialog.
- Design tokens for light and dark themes as CSS custom properties and JSON.
- ESM and CommonJS builds with type declarations; marked `"use client"` for React Server Components setups.
